# Nepal Travel Data Explorer

A small Streamlit app that explores well-known places in Nepal with filters,
ratings, elevation comparison, and a map. Built as a starter project for
Streamlit Community Cloud. All data is a built-in, illustrative sample.

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy on Streamlit Community Cloud

1. Push this folder to a public GitHub repository.
2. Go to https://share.streamlit.io and sign in with the same GitHub account.
3. Create app -> deploy from the repo, main file `streamlit_app.py`.
4. Wait for the build to finish and open the `*.streamlit.app` URL.
